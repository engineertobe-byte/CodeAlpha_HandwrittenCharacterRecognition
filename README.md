# CodeAlpha_HandwrittenCharacterRecognition

A Convolutional Neural Network (CNN) built with PyTorch to identify handwritten characters/digits. Completed as part of the CodeAlpha Machine Learning Internship (Task 3).

## 🎯 Official Task Completed
**Machine Learning Task 3: Handwritten Character Recognition**
- **Objective:** Identify handwritten characters or alphabets.
- **Dataset:** MNIST (digits 0-9), downloaded and stored strictly locally.
- **Model:** Convolutional Neural Networks (CNN) implemented in PyTorch.
- **Execution:** 100% local training and inference. Zero cloud APIs used.
